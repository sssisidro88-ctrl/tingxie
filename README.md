# 阿清哥制作的听写网站 · 雅思听力单词听写

一个**单文件**的雅思听力单词听写练习网页：打开即练，无需安装、无需注册，所有进度只存在你自己的浏览器里。

**在线使用：** https://sssisidro88-ctrl.github.io/tingxie/

---

## 功能

- **单词听写**：自动发音 → 输入拼写 → 回车判定，答错立即显示正确拼写与中文释义
- **内置 350 词**：剑桥雅思听力基础答案词，按每组 30 词分成 12 组，练完一组自动打勾
- **发音可调**：标准英音（RP）/ 在线英音 / 在线美音 / 系统语音，可调语速与每词朗读遍数
- **自动播放保护**：被浏览器拦截时给出一键恢复提示，不会突然没声音
- **在线发音失败自动回退**系统语音，断网也不至于哑掉
- **生词本**：答错自动收录；连续答对 2 次记为掌握并移出
- **生词听写模式**：只考生词本里的词，专攻薄弱项
- **自定义词表**：上传 PDF / TXT 或直接粘贴文本，自动解析成「单词 + 词性 + 中文释义」
  - 支持带编号的表格 PDF（剑桥真题答案词、刘洪波 538 考点词等）
  - 支持换行断词合并、`n./v.` 复合词性、脚注与页眉过滤
- **多词库切换**：进度按词库隔离，互不干扰

## 使用

### 在线

打开 https://sssisidro88-ctrl.github.io/tingxie/ 即可。

### 离线

下载本仓库的 [`index.html`](index.html)，双击用浏览器打开即可，功能完全一样。

> 推荐 Chrome / Edge。iPhone 上请先在页面上点一下再开始，Safari 对自动播放限制更严。

### 导入自己的词表

点右上角「设置」→「上传 PDF 导入」或「粘贴文本导入」，按提示操作。导入后会自动生成分组，并与内置 350 词分开保存进度。

## 说明

- **发音需要联网**：在线发音调用有道词典的公开音频接口；系统语音则使用设备自带语音包，可离线。
- **PDF 导入需要联网**：解析依赖 CDN 上的 PDF.js（jsDelivr）。
- **隐私**：不收集、不上传任何数据。所有学习进度只写在浏览器 `localStorage` 里，换浏览器或清理缓存会重置。
- **技术**：纯静态单文件 HTML + 原生 JS，零依赖、零构建。托管在 GitHub Pages。
